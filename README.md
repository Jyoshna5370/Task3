# Week 3 – SQL Analysis

## 📊 Content Analysis
This project focuses on analyzing the Netflix dataset using SQL queries.  
The goal was to replicate insights previously explored in Pandas and validate them with SQL.

## 🔍 What I Analysed
- Distribution of Movies vs TV Shows  
- Top genres and countries with the most titles  
- Release year trends  
- Average duration of movies  
- Most common ratings  
- Directors with the highest number of titles  
- Subquery analysis: movies longer than average duration  

## 💡 Key Insights
- Movies dominate the dataset compared to TV Shows.  
- Certain genres (like International Movies and Dramas) appear most frequently.  
- The majority of titles were added after 2015, showing Netflix’s rapid expansion.  
- Average movie duration is around ~90 minutes.  
- TV Shows are concentrated in countries like India and the US.  

## 🛠 Tech Stack
- **Database:** MySQL  
- **Languages:** SQL  
- **Tools:** MySQL Workbench, GitHub  

## ✅ Conclusion
This analysis demonstrates how SQL can be used for real-world data exploration.  
By combining **GROUP BY, JOINs, aggregations, and subqueries**, I was able to uncover meaningful insights and validate them against Pandas results.  
The project highlights my ability to work with relational databases and perform analytical queries effectively.
